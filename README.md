# font2header

`font2header.py` converts a `.ttf` font file into a C/C++ header file (`.h`) containing the font data as an `unsigned char` array and its length as an `unsigned int`. Simply place your font file (`SourceSans3-Regular.ttf`) in the project folder and run the script; it will generate `SourceSans3-Regular.h`, which can then be included in your C/C++ project.
